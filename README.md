# Запертая реальность

Сюжетная сборка Minecraft **1.20.1** на **Forge**. Цель — приключение на 20–30 часов: исследование отдельных миров-планет, квесты, уникальные ресурсы и существа, боссы, артефакты и финальное противостояние с магом.

> Сейчас это начальный каркас репозитория, а не готовая игровая сборка. Моды, версии, конфиги и сюжетные главы будут добавляться и проверяться поэтапно.

## Техническая основа

- Minecraft: 1.20.1
- Загрузчик: Forge
- Java для Minecraft 1.20.1: 17
- Планируемые системы: FTB Quests, KubeJS, планетарные измерения и собственные игровые сценарии.
- Язык контента: русский, где это поддерживается модами.

## Структура

- `pack/` — описание сборки и manifest.
- `config/` — конфигурации модов.
- `kubejs/` — рецепты, события и логика прогрессии.
- `quests/` — исходники квестовых глав и тексты.
- `tests/` — автоматические проверки структуры и данных.
- `.github/workflows/` — CI GitHub Actions.

## Автоматические проверки

При каждом push и pull request запускается workflow **Project validation**. На начальном этапе он проверяет JSON, Python-скрипты и целостность manifest. Это не подменяет запуск Minecraft: полноценный smoke-test Forge-сервера будет добавлен после фиксации проверенных версий загрузчика и модов.

## Важное решение о планетах

Ad Astra и похожие моды позволяют путешествовать между планетами/измерениями, но сами по себе не гарантируют настоящую сферическую поверхность планеты. Геометрию миров нужно проверить отдельным прототипом, прежде чем обещать её в финальной сборке.

## Как сообщать о проблеме

Создай GitHub Issue и приложи:
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- `latest.log` или crash-report;
- список установленных модов и версию сборки.
