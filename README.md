# Запертая реальность — Minecraft 1.20.1

Сюжетный модпак для Minecraft Java Edition 1.20.1 на Forge. Цель прохождения — 20–30 часов.

## Что уже включено в исходники

- Автоматический подбор стабильных Forge-версий Ad Astra и KubeJS с обязательными зависимостями через Modrinth API.
- Проверка SHA-1/SHA-512 каждого скачанного JAR.
- Сборка установочного файла Modrinth `.mrpack`.
- KubeJS-сценарий вступления, который отображается игроку при входе в мир.
- Сюжетный план из пяти глав.
- GitHub Actions: unit tests, сборка пакета и запуск тестового Forge dedicated server.

## Требования

- Java 17
- Python 3.10+
- Интернет для загрузки модов и Forge
- Minecraft Launcher, поддерживающий Modrinth modpacks (например, Modrinth App)

## Сборка

```bash
python build.py
```

Готовый пакет появится в `build/locked-reality-0.1.0.mrpack`.

## Локальные проверки

```bash
python -m unittest discover -s tests -v
python build.py
python tests/smoke_server.py
```
