# Запертая реальность — Minecraft 1.20.1

Сюжетный модпак для Minecraft Java Edition 1.20.1 на Forge. Целевая продолжительность будущей полной кампании — 20–30 часов. Текущая сборка — **играбельный ранний этап**, а не законченная кампания.

## Уже реализовано
- Minecraft 1.20.1, Forge 47.4.28, Java 17.
- Ad Astra, KubeJS, YUNG's Better Dungeons и L_Ender's Cataclysm с обязательными зависимостями, автоматически разрешаемыми через Modrinth API.
- Дополнительные подземелья YUNG's Better Dungeons и босс-данжи Cataclysm.
- Три реальные босс-цели: Харбингер, Игнис и Страж Края; их победа открывает следующие фрагменты сюжета.
- Проверка SHA-1/SHA-512 скачанных JAR и сборка Modrinth .mrpack.
- Вступительный текст при входе в мир и пять достижений прибытия на планеты.
- Пять реальных планетарных заданий на сбор ресурсов с несколькими обязательными критериями, опытом и сюжетными наградами.
- Финальная цепочка: ключ Гласио → Страж Края → собственное измерение Цитадели → усиленный босс «Маг — Архитектор» с живой полосой здоровья → финальная награда.
- GitHub Actions проверяет Python-проект, JSON, сборку пакета и запуск выделенного Forge-сервера.

## Как играть в текущую версию
1. Импортировать .mrpack в Modrinth App.
2. Создать новый мир.
3. Открыть меню достижений (обычно клавиша L) и выбрать единую вкладку «Запертая реальность».
4. Лететь на планеты Ad Astra, выполнять задания по сбору ресурсов и получать награды.
5. Победить Харбингера перед главой Венеры, Игниса перед Гласио, затем Стража Края. После этого тебя перенесёт в Цитадель на финальную битву с Архитектором.

## Установка через CurseForge
1. Открой CurseForge App и перейди в Minecraft.
2. Выбери Import и укажи архив `locked-reality-0.1.0-curseforge.zip`.
3. Дождись установки модов и зависимостей, затем запускай профиль на Minecraft 1.20.1 / Forge 47.4.28.

Для CurseForge используется отдельный `manifest.json` с официальными project/file IDs. JAR-файлы модов не вшиваются в архив: клиент загружает их со страниц авторов, а игровые сценарии и настройки идут в `overrides`.

## Сборка и проверки
```bash
python build.py
python build_curseforge.py
python -m compileall -q .
python -m unittest discover -s tests -v
python tests/smoke_server.py
```

## Что ещё не готово до финальной версии
- Длительные многоэтапные квесты с исследованием руин и головоломками.
- Собственные структуры и полноценные данжи на планетах.
- Уникальная модель и собственный AI мага-босса (сейчас это усиленный и переименованный Иссушитель в авторской арене).
- Полноценные концовки с выбором и несколько вариантов исхода.
- Проверенная на реальном прохождении продолжительность 20–30 часов.
- Полноценное игровое тестирование клиентом: CI-сервер подтверждает загрузку, но не заменяет прохождение человеком.

Ad Astra добавляет отдельные планетарные измерения, но не создаёт геометрические сферы. Это отдельная техническая задача, которую нельзя объявить выполненной без отдельного решения и тестов.
