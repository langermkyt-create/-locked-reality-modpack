# Игровая прогрессия — первая версия

Пять реальных триггеров глав подключены к измерениям Ad Astra:

1. Луна — первое свидетельство о тюрьме мага.
2. Марс — фрагмент навигационного ядра.
3. Венера — источник энергии.
4. Меркурий — печать тюрьмы.
5. Гласио — последний рубеж перед цитаделью.

Каждое прибытие в соответствующее измерение выдаёт отдельное достижение и показывает сюжетное сообщение. Это начальная игровая система прогрессии на базе ванильных достижений; полноценная квестовая книга с заданиями, наградами и боссами остаётся отдельной следующей задачей.
