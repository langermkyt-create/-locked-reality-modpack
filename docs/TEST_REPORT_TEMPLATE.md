# Отчёт тестирования

Автоматический workflow проверяет:
1. JSON-структуру manifest и сценарного плана.
2. Наличие исходного KubeJS-сценария.
3. Разрешение совместимых версий модов через Modrinth.
4. Контрольные суммы загруженных JAR.
5. Сборку Modrinth-пакета.
6. Установку Forge 1.20.1 и запуск dedicated server до сообщения `Done`.

Автоматический smoke-test не подтверждает баланс, визуальное качество, прохождение всех сюжетных глав или отсутствие всех клиентских ошибок. Для этого нужны игровые проверки.
